# Global Superstore Sales Analysis

## Project Overview

This project focuses on analyzing Global Superstore sales data to identify business insights related to sales performance, profitability, customer behavior, and regional trends.

The project includes:

* Data Cleaning
* Data Understanding
* Exploratory Data Analysis (EDA)
* KPI Analysis
* Data Visualization
* Interactive Tableau Dashboard

---

# Tools & Technologies Used

* Python
* Pandas
* Numpy
* Matplotlib
* JupyterLab
* Tableau

---

# Dataset Information

The dataset contains:

* Sales transactions
* Customer details
* Product categories
* Shipping information
* Profit and discount data

Total Records: 51,290
Total Columns: 32

---

# Project Workflow

## 1. Data Cleaning

* Handled missing values
* Fixed incorrect data types
* Converted date columns
* Cleaned and prepared dataset for analysis

---

## 2. Data Understanding

Performed initial exploration of:

* Dataset structure
* Data types
* Missing values
* Numerical and categorical columns
* Summary statistics

## 3. Exploratory Data Analysis (EDA)

Performed analysis on:

* Discount vs profit relationship

## 4. KPI Analysis

Calculated important business KPIs:

* Total Sales

# Tableau Dashboard

The interactive dashboard includes:

* KPI Cards
* Monthly Sales Trend Analysis
* Category-wise Sales Performance
* Regional Profit Analysis
* Sub-Category Profit Performance
* Sales by Segment

---

# Key Insights

* Technology category generated the highest sales.
* Consumer segment contributed the highest revenue.
* Some sub-categories showed high sales but low profitability.
* Sales showed an overall upward trend over time.
* Profitability varied across different regions.
